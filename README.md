# PDF_tools
Perform operations and use tools for your pdfs locally

## Table of contents
- [Installation](#installation)
- [Usage](#usage)
- [Why](#why)
- [Contribution](#contribution)

## Installation
1. Clone the reopsitory:
```bash
git clone https://github.com/yaaashhh725/PDF_tools.git
```
2. Create a virtual environment (optional):
```bash
python -m venv environment_name
```
 For windows:
```bash
.environment_name\scripts\activate
```
 For Mac/Linux:
```bash
source environment_name/bin/activate
```
3. Install dependencies:
```bash
 pip install PyPDF2
 ```

## Usage
To run the project, use the following command:
```bash
python pdfTools.py
```

## Why
- For using simple operations like merging pdfs, removing passwords we need to either take subscription of paid software or use online tools.
- Although online tools are free to use, but it compromises privacy of our data in those pdfs.
- So instead clone this repo and use the power of python for free.

## Contribution
If you want to add new tools to this project you can do so by:
- Creating new branch with the branch name as the tool name
- Issuing a pull request with a clear description of the tool and its purpose

Before contributing, please make sure to:
- Follow the code style and formatting guidelines used in the project
- Write clear and concise commit messages
- Include documentation or usage instructions if your tool requires it
- Add tests if applicable, or verify your code works as expected
- Check for duplicate tools or existing features before starting
- Link any related issues in your pull request description
